### Project Overview
This project analyzes how media sources framed the 2026 Iran War using news article text across 77 media sources. We use LLM-based scoring to compare coverage across five framing dimensions: kinetic, humanitarian, diplomatic, economic, and culpability bias, and explore patterns through temporal, text-based, and network visualizations.
